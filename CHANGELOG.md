# Changelog

## 0.1.0 — initial release candidate

- Standalone synchronous client for the Bond by ISIN JSON API.
- Bond lookup, complete stored history, cash flows, dated analytics,
  government and swap Z-spreads, curves, ratings, auctions and bond ETFs.
- Explicit search pagination, environment API keys, bounded GET retries,
  timeouts and typed exceptions.
- Unmodified API payloads with dates, provenance, nulls and zeroes preserved.
- Tests, usage examples, distribution checks and Trusted Publishing workflow.
