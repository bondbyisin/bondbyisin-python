Python library

Install the standalone Bond by ISIN client:

python -m pip install bondbyisin
from bondbyisin import Client

with Client() as client:  # Reads BOND_API_KEY from your environment.
    matches = client.search("oracle")
    bond = client.bond("68389XBU8")
    history = client.history("68389XBU8")

These exact examples work without a key. Other securities, dates and filters require an active API subscription. Get your key from your account.
